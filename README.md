# Hospital Management System

## Description

The Hospital Management System is a web-based application developed to manage hospital activities digitally. It helps in maintaining patient records, managing doctor appointments, handling billing, and storing staff details efficiently. The project reduces manual work and improves the overall management process.

## Features

* Patient record management
* Doctor appointment booking
* Staff management
* Billing system
* Secure login and authentication

## Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Server: XAMPP

## Requirements

* XAMPP Server
* Web Browser

## Installation Steps

1. Install XAMPP on your system.
2. Copy the project folder into the `htdocs` folder inside the XAMPP directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin and create a new database.
5. Import the SQL file into the database.
6. Open the browser and run the project using:

   ```
   http://localhost/project-folder-name
   ```

## Objective

The main objective of this project is to simplify hospital management by providing a digital platform for handling hospital operations efficiently.
